  dt = frame_dt / num_substeps

  for substep in 1..num_substeps:
      #--- predict ------------------------------------
      for p in particles:
          p.vel += dt * (gravity + externalForce(p))
          p.prevPos = p.pos
          p.pos     = p.pos + dt * p.vel    # x* predictor

      #--- rebuild uniform grid -----------------------
      clearCounts()
      for p in particles:
          cell = gridIndex(p.pos)
          counts[cell]++
      prefixSum(counts, starts)
      for p in particles:
          cell = gridIndex(p.pos)
          writeIndex = atomicInc(counts[cell])   # or a simple counter on CPU
          compact[ starts[cell] + writeIndex ] = p.id

      #--- build neighbor-contact list ----------------
      contacts.clear()
      for cell in grid:
          for each particle i in cell:
              for each neighbor-cell of cell:
                  for each particle j in neighbor-cell:
                      if j > i and overlap(i,j):
                          contacts.push( contact(i,j) )

      # color contact list so pairs sharing a particle aren’t in same group
      partitions = colorContacts(contacts)

      #--- Gauss–Seidel solver iterations -------------
      for iter in 1..num_constraint_iters:

          # collision partitions first
          for part in partitions:
              for c in part:
                  projectCollisionPairGaussSeidel(c.p, c.q)

          # voxel Gram–Schmidt constraints (disjoint sets)
          for vox in voxels:
              projectVoxelShapeConstraint(vox.cornerParticles)

          # face constraints (three non-overlapping partitions)
          for axis in {X, Y, Z}:
              for face in faceConstraints[axis]:
                  if face.active:
                      if beyondStrain(face):
                          face.active = false
                      else:
                          projectFaceShapeConstraint(face.particles)

      #--- velocity update ----------------------------
      inv_dt = 1 / dt
      for p in particles:
          p.vel = (p.pos - p.prevPos) * inv_dt



  projectCollisionPairGaussSeidel(p, q):
      diff   = p.pos - q.pos
      dist   = length(diff)
      minDist = p.radius + q.radius
      if dist >= minDist or dist == 0:
          return

      dir     = diff / dist                         # contact normal from q->p
      penetration = minDist - dist

      wsum = p.invMass + q.invMass                 # reciprocal masses
      if wsum == 0:
          return                                   # both static

      correction = dir * (penetration / wsum)
      if p.invMass > 0:
          p.pos += correction * p.invMass
      if q.invMass > 0:
          q.pos -= correction * q.invMass




With the data we have now, Gauss–Seidel-style collision handling just becomes another position-based constraint pass that touches
  the particle fields you already added (pos, predicted_pos, prev_pos, vel, inv_mass). A CPU sketch for one substep looks like this:

  - Predict – for every voxel/particle, move to predicted_pos = pos + vel * dt; cache prev_pos = pos.
  - Collide (Gauss–Seidel) – walk particles one constraint at a time and resolve immediately:
      - Static environment/ground: test predicted_pos against planes or AABBs, compute penetration depth and normal, then correct
        predicted_pos by -penetration * n. Because we update in place, later constraints see the corrected state—this is the Gauss–
        Seidel benefit.
      - Player or other bodies: do the same against each player capsule/box (or any analytic collider).
      - Particle–particle (optional): to collide two voxels, use the voxel hash to find neighbouring voxels, iterate their eight
        particles, check sphere overlap (radius = VOXEL_SIZE * 0.5f from the paper), and push the pair apart proportionally to their
        inverse masses.
  - Accumulate – after all collision constraints (and the VGS/face constraints) finish, update velocities with vel = (predicted_pos -
    prev_pos) / dt and commit pos = predicted_pos.

  Because each voxel owns its particles, you don’t need partitioning; just running these corrections inside the constraint loop keeps
  everything Gauss–Seidel.
